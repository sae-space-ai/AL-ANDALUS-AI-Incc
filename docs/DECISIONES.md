## Decisiones Aprobadas

### DEC-001: Identidad Corporativa
- **Fecha:** FASE 0
- **Decisión:** La empresa se denominará AL-ANDALUS AI.
- **Producto principal:** ANDALUS RE (REA).
- **Lema:** INTELLIGENCE · ENGINEERING · EUROPE.
- **Colores:** Verde andaluz y blanco.
- **Anagrama:** Microchip blanco sobre fondo verde andaluz.
- **Estado:** ✅ Aprobada.

### DEC-002: Conservación de REA
- **Fecha:** FASE 0
- **Decisión:** Se conservará íntegramente el código y documentación de REA.
- **Repositorio:** https://github.com/morluto/rea
- **Regla:** No eliminar ni sustituir componentes originales sin autorización.
- **Estado:** ✅ Aprobada.

### DEC-003: Distinción de JOULE
- **Fecha:** FASE 0
- **Decisión:** Se distinguen dos proyectos separados:
  - JOULE Compute Governor (optimización de costes).
  - JOULE SENSE 360° (análisis visual con OpenCV).
- **Estado:** ✅ Aprobada.

### DEC-004: Referencia del 25 %
- **Fecha:** FASE 0
- **Decisión:** La reducción del 25 % declarada por el propietario se trata como referencia, pendiente de verificación experimental.
- **Estado:** ✅ Aprobada. No se inventarán benchmarks.

### DEC-005: Filosofía de Orquestación
- **Fecha:** FASE 0
- **Decisión:** La orquestación de agentes se inspira en el contrapunto de Bach.
- **Principios:** Especialización, activación selectiva, economía de recursos.
- **Estado:** ✅ Aprobada.

### DEC-006: EU Inc. — Estado Jurídico
- **Fecha:** FASE 0
- **Decisión:** EU Inc. es una figura jurídica prevista, no constituida.
- **Regla:** No presentar la empresa como constituida hasta confirmación legal.
- **Estado:** ✅ Aprobada.

### DEC-007: Anagrama Original
- **Fecha:** FASE 0
- **Decisión:** El anagrama original es obligatorio. Si falta su archivo gráfico, se solicitará al propietario.
- **Regla:** Nunca inventar ni sustituir el logotipo.
- **Estado:** ✅ Aprobada. Dependencia pendiente.

### DEC-008: Arquitectura de Integración
- **Fecha:** FASE 1
- **Decisión:** La integración de REA se realizará mediante capas independientes.
- **Regla:** vendor/rea/ es SOLO LECTURA. Las extensiones viven en apps/ y packages/.
- **Estado:** ✅ Aprobada.

### DEC-009: No Reconstruir JOULE sin Código Original
- **Fecha:** FASE 1
- **Decisión:** No se reconstruirá JOULE Governor ni JOULE SENSE 360° sin localizar su código original.
- **Estado:** ✅ Aprobada.

### DEC-010: Auditoría Web de REA
- **Fecha:** FASE 1
- **Decisión:** Se ha auditado la web rea.tools: 20 idiomas, 18+ páginas, 5 casos de estudio, 1,728+ mensajes por idioma.
- **Regla:** Preservar todo el contenido al personalizar para ANDALUS RE.
- **Estado:** ✅ Aprobada.
