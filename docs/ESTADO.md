## Riesgos Identificados

| Riesgo | Impacto | Mitigación |
|---|---|---|
| Pérdida de código REA | 🔴 Crítico | Conservación estricta, capas independientes, vendor/ como solo lectura |
| Confusión entre JOULE Governor y SENSE | 🟡 Medio | Documentación clara, separación de módulos |
| Publicación prematura | 🔴 Alto | Regla: no publicar sin permiso |
| Gastos no autorizados | 🔴 Alto | Regla: no generar gastos sin permiso |
| Reconstruir JOULE sin código original | 🟡 Alto | Regla: no reconstruir sin localizar código |
| Modificar REA sin autorización | 🔴 Crítico | vendor/ como solo lectura, integración por APIs |
